## 1. Контент

### Подготовка

- [ ] **Переводы интерфейсов, товаров и сервисных страниц** — если локаль новая, заранее убедиться в наличии переводов; при отсутствии поставить задачу контент-менеджеру — *контент-менеджер, PO* — ~4 ч интерфейсы, ~4 ч товары
- [ ] **Переводы свойств и категорий в админке** — *контент-менеджер* — ~4 ч
- [ ] **Апрув переводов у носителя языка** — после добавления переводов в интерфейс получить подтверждение корректности — *PO*
- [ ] **Перечень валют и способов оплаты** — определить список для домена; если валюта новая, уточнить у разработки, поддерживается ли она выбранными способами оплаты — *PO, менеджер по развитию* — ~1 ч

### Основные работы

- [ ] **Контакты в шапке и футере** — телефон и e-mail, админка → Инфоблоки — *контент* — ~1 ч
- [ ] **Валюта по умолчанию** — админка → Домены → выбрать валюту для нового домена — *контент* — ~30 мин
- [ ] **Способы оплаты** — админка → Домены → выбрать способы оплаты для нового домена — *контент*
- [ ] **Настройка фильтров** — админка → Свойства товаров; добавить свойство в категорию товаров, справочники → категории. Для существующих свойств переводы и фильтр каталога уже есть, операция выполняется по необходимости — *контент* — ~4 ч
- [ ] **Страницы для футера** — страницы типа sitepage создаются через админку — *контент*
- [ ] **Товары на главной и посадочных** — админка → Блоки на главных страницах; на страницах городов и стран товары появляются автоматически. Общие блоки копируются с ближайшего домена, поэтому проверить актуальность списка и настроить в каждом заголовок, надпись и ссылку на кнопке на нужной локали — *контент* — ~4 ч
- [ ] **Блог** — проверить актуальность статей, добавить новые при необходимости — *контент, SEO*
- [ ] **SEO-тексты на посадочные** — объём зависит от числа открываемых страниц; закладывать тексты на страны, главную и основные категории — *копирайтер, SEO* — ~2 ч

### После запуска

- [ ] **Актуальность цен и наценок для домена** — *менеджер по развитию* — ~1 день

## 2. Разработка

### Подготовка

- [ ] **Домен приобретён** — купить или убедиться в наличии прав и доступов. Выполняется заранее по заявке, в общую оценку не входит — *PO, PM по инфраструктуре*
- [ ] **Домен закрыт от индексации** — на время разработки — *разработка* — ~30 мин

### Основные работы

- [ ] **Домен в списке MGF** — добавить в константу `DomainReference::MGF_IDS` — *разработка* — ~5 мин
- [ ] **Каталог catalogOffers** — скопировать с наиболее похожего домена, `./artisan tmp:new-domains-catalog`; пересчёт выполняется сам — *разработка* — ~30 мин
- [ ] **Валюты по умолчанию в справочнике стран** — `./artisan tmp:new-domains-country-currencies` — *разработка* — ~30 мин
- [ ] **Геостраницы geopages** — `./artisan tmp:new-domains-geopages` — *разработка* — ~30 мин
- [ ] **Меню каталога** — `./artisan tmp:new-domains-menu` — *разработка* — ~30 мин
- [ ] **ProductBlocks** — `./artisan tmp:copy-product-blocks-to-new-domains` — *разработка* — ~4 ч
- [ ] **HomePages** — `./artisan tmp:copy-homepages` — *разработка*
- [ ] **Переводы стран** — проверить наличие нужной локали в конфиге `app.locales`, затем `import:countries-names` — *разработка*
- [ ] **Переводы городов** — `import:cities-names` только для нужной локали: первым проходом все переводы, вторым только предпочтительные. Столицу и крупные города актуализировать руками — название и слаг на локали — *разработка*
- [ ] **SitePages** — `./artisan tmp:new-domain-<locale>-site-pages`, затем `tmp:copy-site-pages` — *разработка* — ~2 ч
- [ ] **Перегенерация меню** — `./artisan menu:generate-for-cities --domain_id=<id>` — *разработка* — ~1 ч
- [ ] **Перенос блога** — проверить, что статьи с других доменов не копируются — *разработка* — ~2 ч
- [ ] **hreflang** — должен работать после добавления домена в список MGF, проверить фактические значения — *разработка* — ~2 ч
- [ ] **Шаблоны писем** — админка → `/admin/notices` — *разработка* — ~2 ч
- [ ] **Футер** — заполняется хардкодом для каждого домена — *разработка* — ~1 ч
- [ ] **Генерация sitemap** — `./artisan sitemap:generate` — *разработка* — ~1 ч
- [ ] **Проверка генерации sitemap** — пройти по ссылкам каждого раздела карты сайта — *разработка* — ~2 ч
- [ ] **Карта на главной** — добавить домен в Google Maps через PM по инфраструктуре; если карта не заработала, эскалировать на тех. лида — *PM*

### После работы SEO

- [ ] **Тестирование нового домена** — основные пользовательские истории, особое внимание оплатам — *QA*
- [ ] **Домен в аккаунте me-talk** — добавить и удостовериться в работоспособности чатов — *PO* — ~1 ч
- [ ] **Коэффициент конвертации валют** — уточнить у финансов, нужен ли дополнительный коэффициент; обычно курс 1 к 1 — *PO* — ~1 ч

## 3. SEO

### Основные работы

- [ ] **robots.txt** — настроить: скопировать с похожей локали MGF и при необходимости скорректировать — *SEO* — ~1 ч
- [ ] **Донастройка меню каталога** — копирование не всегда соответствует требованиям SEO — *SEO* — ~1 ч
- [ ] **Создание и открытие посадочных** — нужные страны, города, страницы категорий и праздников; проверить отсутствие noindex. Объём зависит от первоначального списка, обычно все страны, столицы и основные категории — *SEO, контент* — ~1 день
- [ ] **Сервисные страницы** — проверить корректность: исходящие ссылки, упоминаемые домены. Перечень страниц и url определить раньше остального — он блокирует настройку верхнего и нижнего меню — *SEO* — ~1 ч
- [ ] **Метатеги** — разместить подготовленные шаблоны, отдельно прописать мету главной страницы и важных категорий — *SEO* — ~1 ч
- [ ] **Перелинковочный блок на главной** — *SEO* — ~1 ч
- [ ] **Перелинковочные блоки на гео-страницах** — проверить корректность — *SEO* — ~1 ч
- [ ] **Проверка сайта пауком** — отсутствие пустой и дублирующейся меты, ошибок 5xx, 4xx, 3xx — *SEO* — ~1 ч

### После проверки тестировщика

- [ ] **hreflang** — финально проверить после открытия домена: ошибки, соответствие документации Google — *SEO* — ~1 ч
- [ ] **Генерация sitemap** — финально проверить после открытия домена — *SEO* — ~1 ч
