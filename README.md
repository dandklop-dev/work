## Подписка на цветы

`subscription/` → https://dandklop-dev.github.io/work/subscription/

Кликабельный прототип нового флоу подписки на цветы для мобильного приложения.
Собран на токенах дизайн-системы приложения: Montserrat, трекинг −2%,
шкала 20/17/16/15/14/13/12, акцент `#D93C82`, фон `#F2F3F5`, радиусы 8/12.

Флоу: `Приветственный` → `Для кого` → `Размер букета` → `Расписание` → `Оформление` → `Готово`

Проходится в двух сценариях — «себе» с оплатой перед каждой доставкой
и «в подарок» с оплатой за весь срок.

Цены и содержимое букетов — примерные, фотографии заменены иллюстрацией.

## Выбор категории в Google Play

`play-category/` → https://dandklop-dev.github.io/work/play-category/

Сравнительный анализ четырёх категорий Google Play для запуска Fendora:
Parenting, Lifestyle, Tools, Maps & Navigation. По каждой — соответствие
продукту, уровень конкуренции, ожидаемый CTR и риски stalkerware-модерации.

Вывод: Parenting — там же находятся ключевые конкуренты, выше intent
пользователя и ниже риск автоматических проверок на шпионское ПО.

Оценки конкуренции и конверсии — экспертные, не выгрузка из Play Console.
