## Подписка на цветы

`subscription/` → https://dandklop-dev.github.io/work/subscription/

Кликабельный прототип нового флоу подписки на цветы для мобильного приложения.
Собран на токенах дизайн-системы приложения: Montserrat, трекинг −2%,
шкала 20/17/16/15/14/13/12, акцент `#D93C82`, фон `#F2F3F5`, радиусы 8/12.

Флоу: `Приветственный` → `Для кого` → `Размер букета` → `Расписание` → `Оформление` → `Готово`

Проходится в двух сценариях — «себе» с оплатой перед каждой доставкой
и «в подарок» с оплатой за весь срок.

Цены и содержимое букетов — примерные, фотографии заменены иллюстрацией.
